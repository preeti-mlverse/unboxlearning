Pipeline plan: reach AstraXR level, then differentiate

What the content pipeline is made of, what is built, what a coding agent can and cannot do, which open-source projects to use, and how to build it in the right order on a $3 OpenAI budget.

Short answer: no, export should not come first. It is the last stage of the pipeline and adds nothing to learning quality.

Build in this order. First, a cheap way to test. Then the input side (reading content well). Then the quality and cost of generation. Then the learner experience. Distribution (export, marketplace) comes last.

Most of the early work uses free, local open-source tools. Only phases 2 and 3 spend OpenAI credit, about $1.50 in total. The rest of the $3 stays in reserve for test courses.

2. Agents: in the product and in the building

Inside the product, the pipeline should stay a fixed workflow: each step calls the model once, with a set structure for the output. It should not use autonomous agents that decide their own steps. A fixed workflow is cheaper, gives the same result each time, and is easy to test. The only place agent-like behaviour earns its cost is the learner's tutor chat.

For building it, the work splits three ways:

A coding agent builds it

Nearly all the software

  • Wiring in docling, Whisper, fastembed and FSRS
  • Pipeline stages, caching, cost caps
  • Card player, games, interactive widgets
  • Avatar integration and lip-sync
  • Analytics dashboards
  • SCORM, cmi5 and HTML5 export
  • Tests and quality benchmarks
The agent builds it, you decide or supply

Taste and inputs

  • Avatar look and voice
  • Your character illustrations
  • 4–6 real sample materials from target customers
  • What "good enough" looks like: approve 2 reference courses
  • Target learning platform (Moodle, TalentLMS …)
  • Plans, limits and prices
Outside coding

People, accounts, legal

  • Subject experts spot-checking courses
  • Real learners trying it
  • Payment account and verification (Stripe or Razorpay)
  • Terms, privacy, rights to uploaded content
  • Hosting account; OpenAI top-up
  • A free SCORM Cloud account for export testing

4. Making $3 go far

Measured on the water-cycle test course built today (4 modules, 48 cards). Text generation cost about $0.42; six illustrations added a few cents more. Nearly all of it is output from the top model:

Write modules$0.17
Repair round$0.12
Knowledge graph$0.05
Extract ideas$0.03
Profile content$0.02
Outline$0.02
Fact-check$0.01
Violet: top model (gpt-5). Aqua: smaller model (gpt-5-mini). Illustrations use gpt-image-1-mini at low quality and aren't shown.

Four moves bring a course to roughly $0.08–0.12. At that price, $3 covers 25–30 test courses instead of about 7.

  • Write with the smaller model. gpt-5-mini costs a fifth of gpt-5 on output. Test it first on one module side by side, for about $0.05.
  • Cut the repair round. Three of the four modules needed one. Most failures are simple rule breaks (too long, reading level too high), and a tighter first prompt or a code fix can prevent them.
  • Cache every stage. Re-running one stage should never redo the stages before it.
  • Develop the interface for free. Record real responses once and replay them while building screens.

Also free: local embeddings, docling, Whisper, Kokoro voice and diagrams drawn from data. A free provider for development is an option too: Google's Gemini API has a rate-limited free tier, and our gateway can add it. Check its data terms first, and use it only for test material, never customer content.

5. Build order

0

Foundations for cheap testing

$02 days
  • Hard spending cap per run in the model gateway, and a cost meter on each course
  • A fixed test set of 6 short sources: a textbook PDF, a scanned page, a slide deck, a docs page, a YouTube video and a spreadsheet
  • Stage-by-stage caching, and a record-and-replay mode for interface work
Done when: the whole test set runs in replay mode for $0, and a real run stops at the cap.
1

Read content properly: ingestion bake-off

$03 days
  • docling vs our parser vs markitdown on the test set; trafilatura vs our web reader
  • faster-whisper plus yt-dlp for videos without captions; fastembed in place of paid embeddings
  • Keep whichever wins on each format, with the others as fallback
Done when: a side-by-side report shows the parsed output per file, and the scanned and maths pages read correctly.
2

Better courses for less

≈ $13 days
  • Side-by-side test of gpt-5 vs gpt-5-mini on the same module; switch if quality holds
  • Stronger prerequisite links in the concept graph; fewer repair rounds
  • promptfoo rule tests on every card: length, reading level, answer key, source evidence
Done when: a course costs ≤ $0.12 and the rule tests pass on the test set.
3

AstraXR-level learner experience

≈ $0.508 days
  • 3D talking tutor: TalkingHead + Kokoro voice, both free
  • "Show me" visuals on any card: diagrams are free, pictures are capped per day
  • Progress page and creator dashboard with insights; FSRS reviews and pyBKT mastery
  • Module video lessons rendered from existing cards with Motion Canvas
Done when: one course can be learned start to finish with the avatar, reviews and video, and the dashboards show real attempts.
4

Distribution

$05 days
  • Access levels: private, restricted, public catalogue
  • SCORM 1.2/2004, cmi5 and HTML5 export, tested in SCORM Cloud and your target platform
  • Groundwork for the marketplace (payments come later)
Done when: an exported course imports into your target learning platform and reports score and completion.
5+

Differentiation

after parity
  • Duolingo layer: many question variants per concept, a difficulty model, adaptive sessions, the learning path, leagues and review of past mistakes
  • Brilliant layer: the learner tries before being told, using a library of draggable, sliding interactives that the engine configures for each concept
  • Language lab, then the full marketplace

6. Decisions needed from you

  1. Smaller model for writing. May we switch course writing to gpt-5-mini if the side-by-side test shows the same quality? It is the biggest saving.
  2. Free test provider. May we add Gemini's free tier for development, using test material only?
  3. Test material. Can you share 4–6 real files your target customers would upload, to use as the fixed test set?
  4. Avatar style. Realistic 3D person, stylised 3D character, or your own illustrations animated in 2D?
  5. Target learning platform. Which one do your first customers use? Moodle, TalentLMS, Cornerstone or another?
